# Muhammadali — Personal Website

GitHub Pages personal bio/portfolio site.

## Structure
- `index.html` — main page
- `css/style.css` — design and Wuthering Waves font
- `js/main.js` — language switching
- `assets/fonts/` — supplied font

## Languages
English, Uzbek, Russian, Japanese and Chines. The first visit uses the browser language; the selected language is saved locally.
